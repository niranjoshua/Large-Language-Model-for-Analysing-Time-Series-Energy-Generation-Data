What it does

A forecast is only useful if you can trust it and act on it.

So Vaticore is built around three things: honest uncertainty, honest evaluation, and a decision at the end.

01 / forecast

Probabilistic by default

Every forecast is a range, not a single number. You see the likely case and the bad case, because a battery sized for the average day fails on the worst one.

02 / evaluate

Measured against a baseline

Every model is backtested on held-out history and scored against a naive baseline. If it cannot beat “same as yesterday,” it does not ship. No cherry-picked numbers.

03 / decide

Answers, not just charts

The forecast becomes an operational call: recommended battery reserve and whether to plan generator runtime over the next window. Advisory only, never automatic control.

Evidence

Built to survive due diligence.

The engine is a probabilistic gradient-boosting model, evaluated with rolling-origin backtests and scored on pinball loss — the metric that rewards well-calibrated ranges, not just a good average.

1

Ingest messy data

Validated schema, timezone normalisation, gap detection. Built for sparse, imperfect operator feeds.

2

Forecast with weather

Calendar and lag features plus live weather from Open-Meteo drive per-site load and solar forecasts.

3

Score honestly

Rolling-origin backtest against persistence on every run, so accuracy claims are reproducible.
